# 终端与 Shell — 你第一次打开的那个黑窗口

> 如果你刚接触 Linux，桌面上的那个黑窗口可能让你不知所措。这章带你从零开始。

---

## 它到底是什么？

在 Windows 上，你用鼠标双击图标来"做事情"。在 Linux 上，很多事要用**打字**来完成——终端就是那个打字的窗口。

```
Windows 的操作方式：                  Linux 的操作方式：
鼠标点击图标 → 打开软件              打字 → 回车 → 软件运行
                                       ↑
                                    这个"打字的黑窗口"就是终端
```

**"终端"（Terminal）**是那个黑窗口本身，**"Shell"（壳）** 是窗口里面那个"听你打字、帮你干活"的程序。

你可以把 Shell 想象成一个翻译：你把想做的事用英语（命令）说给它听，它翻译成计算机能懂的机器语言去执行。

---

## 你天天会用到的 5 条命令

### 1. `ls` — 看看这个目录里有什么

```bash
ls
# 输出当前目录里所有文件和文件夹的名字

ls -l
# 输出详细信息（大小、权限、修改时间）

ls -a
# 输出隐藏文件（以 . 开头的文件，如 .gitignore）
```

### 2. `cd` — 去别的目录

```bash
cd ~/projects/g1-rl           # 去项目的根目录
cd ..                          # 去上级目录
cd                             # 回家目录（/home/你的用户名）
```

> `~` 是一个缩写，等于 `/home/你的用户名`。`~` 比完整路径短，大部分教程都用它。

### 3. `pwd` — 我现在在哪儿？

```bash
pwd
# /home/lyh/projects/g1-rl
```

### 4. `mkdir` — 新建文件夹

```bash
mkdir my_new_folder           # 创建文件夹
mkdir -p a/b/c                # 一次创建嵌套的文件夹（a 里有 b，b 里有 c）
```

### 5. `cat` — 看文件内容

```bash
cat README.md                 # 把文件内容打印到屏幕上
```

## 路径：那些 `~` `/` `.` `..` 到底什么意思？

```
/                           ← 根目录（整个文件系统的最顶层）
│
├── home/
│   └── lyh/                ← 你的家目录（~ 就是这）
│       └── projects/
│           └── g1-rl/     ← 项目目录
│               ├── README.md
│               └── scripts/
│
├── usr/
├── etc/
└── tmp/
```

| 符号 | 什么意思 | 例子 |
|------|----------|------|
| `/` | 绝对路径的起点，或路径的分隔符 | `/home/lyh` |
| `~` | 你的家目录 | `~/projects/g1-rl` = `/home/lyh/projects/g1-rl` |
| `.` | 当前目录 | `./scripts/start.sh` |
| `..` | 上级目录 | 从 `~/projects/g1-rl/scripts` 运行 `cd ..`，就回到了 `~/projects/g1-rl` |

## `sudo` — "以管理员身份运行"

Linux 不是人人都能随便装软件的。普通用户只能改自己的文件，系统文件动不了。**`sudo`** 就是"借管理员的权限做这件事"。

```bash
apt install docker.io           # ❌ 普通用户不能装软件
sudo apt install docker.io      # ✅ 借管理员权限来装
```

它会让你输入你的密码（输入时屏幕上不会显示 `***`，这是正常的，打完直接回车就行）。

## 快捷键

| 按键 | 作用 |
|------|------|
| `Ctrl+C` | 停止当前正在跑的程序（训练跑太久了？`Ctrl+C` 停掉） |
| `Ctrl+D` | 发送"输入结束"信号（常用来退出 Python shell 或终端） |
| `Ctrl+L` | 清屏（和 `clear` 命令一样） |
| `↑` / `↓` | 翻阅之前输过的命令（不用重新打一遍） |
| `Tab` | 自动补全文件名（打一半按 Tab，自动填完） |

## 没人会告诉你但你应该知道的

1. **终端里输入密码时不会显示 `***`**。你以为键盘坏了，其实没坏——Linux 就是不显示。打完直接回车。

2. **空格在 Linux 里是有意义的**。`cd ~/projects/g1-rl` 不能写成 `cd ~/projects/ g1-rl`。

3. **文件删了就没了**。Linux 没有"回收站"这个概念。`rm` 就是永久删除，所以看到 `rm -rf` 命令的时候**看清楚再回车**。

4. **`.sh` 文件就是终端命令的合集**。你完全可以把今天学的这些命令写到一个 `.sh` 文件里，一行一条，下次直接 `bash 文件.sh` 就全部执行了。这就是脚本。

5. **你不需要背所有命令**。需要的时候回来查就行。用多了自然会记住。
