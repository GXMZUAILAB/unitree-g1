# 硬件与操作系统 — 为什么选 Ubuntu？GPU 是什么？

> 你平时用 Windows 或 Mac，为什么做机器人要用 Ubuntu？GPU 和 CPU 有什么区别？

---

## 操作系统：为什么不用 Windows？

### 三个操作系统的简单对比

| | Windows | macOS | Linux (Ubuntu) |
|---|---|---|---|
| **谁开发的** | 微软 | 苹果 | 开源社区 |
| **面向谁** | 普通用户、游戏玩家 | 设计师、开发者 | 服务器、机器人、嵌入式 |
| **装软件的方式** | 双击 `.exe` *下一步下一步* | 从 App Store 下载 | 终端里敲 `apt install` |
| **命令行重要度** | 偶尔用 | 一般 | 天天用——这就是终端的作用 |

### 为什么机器人、AI 训练都用 Linux？

1. **免费**：不用买许可证。机器人团队可能管理几十台电脑，省下的 license 费够再买一台机器人
2. **开源**：整个操作系统谁都能看到源码。出了问题能查到根源（Windows 蓝屏时你只能重启）
3. **社区**：NVIDIA GPU 驱动、ROS 机器人框架、Docker 容器——这些工具都是先在 Linux 上开发和测试的
4. **远程**：服务器没有显示器。Linux 天然支持纯命令行操作，Windows 离不开图形界面

### 为什么这个项目选了 Ubuntu 26.04？

- **Ubuntu** 是最流行的 Linux 发行版之一，新手最友好
- **26.04** 是 2026 年 4 月发布的最新 LTS 版（Long Term Support，支持到 2031 年）
- 但有个坑：**Isaac Sim 官方只支持 22.04/24.04**。26.04 太新了，所以我们用 Docker 绕过去——在容器里跑一个虚拟的 24.04

## GPU 是什么？

### CPU vs GPU

| | CPU | GPU |
|---|---|---|
| **全称** | 中央处理器 | 图形处理器/显卡 |
| **长什么样** | 一个小方块（Intel/AMD） | 一块大板子（NVIDIA） |
| **擅长什么** | 一个任务接一个任务，每个都很快 | 几千个简单任务同时做 |
| **类比** | 1 个数学博士做微积分 | 1000 个小学生做加减法 |
| **用在哪** | 打开浏览器、运行操作系统 | 游戏渲染、AI 训练、视频剪辑 |

**AI 训练为什么用 GPU？**

神经网络的计算就是几百万次矩阵乘法——本质是"很多简单计算"。这正是 GPU 擅长的：
- CPU：`1 × 1000000` 次计算，一次一次来
- GPU：`1000 × 1000` 次计算，同时进行

> 所以训练 G1 需要一张 NVIDIA 显卡。你的 CPU 再强，用纯 CPU 跑 RL 训练也会慢 10-100 倍。

### 为什么必须是 NVIDIA？

AI 训练用 **CUDA** 这个技术让 GPU 并行计算。CUDA 是 NVIDIA 开发的，只能在 NVIDIA 显卡上用。

- ✅ **NVIDIA**（RTX 3060/3080/4060/4080……）：支持 CUDA，能用 Isaac Sim
- ❌ **AMD 显卡**：不支持 CUDA（虽然有 ROCm，但在 Isaac Sim 上不兼容）
- ❌ **Intel 核显**：性能太弱，不够跑仿真

## 硬件检查

跑下面几条命令确认你的电脑合格：

```bash
# 1. GPU 型号和驱动
nvidia-smi
# 应该看到 "NVIDIA GeForce RTX xxxx" + "Driver Version: 580.x"

# 2. 显存
nvidia-smi --query-gpu=memory.total --format=csv,noheader
# 输出类似 "16384 MiB" = 16GB ✅

# 3. 磁盘空间
df -h /home/
# Available 列 > 100GB

# 4. 内存
free -h
# Mem total > 16GB
```

## 硬件最低要求

| 硬件 | 最低 | 推荐 |
|------|------|------|
| GPU | NVIDIA RTX 3060 (8GB 显存) | RTX 3080 Ti / RTX 4080 (16GB+) |
| 内存 | 16 GB | 32 GB |
| 磁盘 | 100 GB 可用 | 300+ GB SSD |
| 系统 | Ubuntu 22.04+ | Ubuntu 24.04 |

### 哪些不能跑？

- **AMD 显卡**：不支持 CUDA
- **GTX 系列**：不支持 RTX 光追核心，Isaac Sim 需要
- **显存 < 8GB**：可以加载但不能训练
- **Mac**：Isaac Sim 没有 Mac 版

## 驱动版本——580.x 是硬性要求

**Isaac Sim 5.1.0 只兼容 NVIDIA 驱动 580.x！**

| 驱动版本 | 能跑吗 | 解释 |
|----------|--------|------|
| 580.x | ✅ | Isaac Sim 官方支持 |
| 595.x | ❌ | 会崩溃（segfault），是已知 bug |
| 535.x | ⚠️ | 没充分测试 |

```bash
# 检查你的版本
nvidia-smi | head -3
# "Driver Version: 580.159.03" → ✅
# "Driver Version: 595.71.05" → ❌ 需要降级
```

如果版本不对，跳到 [1.4_GPU驱动](../1_environment/1.4_nvidia_driver_gpu.md) 看怎么装/换驱动。

## 一个你可能没意识到的认知

> **你不需要「懂 Linux」才开始。你需要的是「敢在 Linux 上用」。**  
> 会打开终端、会敲 `ls` 和 `cd`、会复制粘贴命令——这就够开始做 RL 训练了。
>
> Linux 不是你学的第一门课，是你学别的课的"环境"。在跑训练的路上遇到 Linux 不懂的，搜一下就行。
