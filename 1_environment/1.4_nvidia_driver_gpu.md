# GPU 驱动 — 为什么 580 能跑，595 会崩？

> 这是整个项目最坑的一个点。我们在这里卡了好几个小时。看完这章，你不用再卡一次。

---

## 什么是 GPU 驱动？

GPU 驱动是**操作系统和显卡之间的翻译官**。

```
你的程序（如 Isaac Sim）
    │
    │  "我要渲染 3D 画面"
    │
    ▼
┌──────────────┐
│  GPU 驱动     │  ← 翻译官：把"渲染3D画面"翻译成显卡能懂的指令
│  nvidia.ko    │
└──────────────┘
    │
    │  "执行这些十六进制指令"
    │
    ▼
┌──────────────┐
│  RTX 3080 Ti │  ← 真正的硬件
└──────────────┘
```

**没有驱动，或者驱动版本不对，显卡等于没插。**

---

## 怎么检查？

```bash
nvidia-smi
```

输出第一行：

```
+-----------------------------------------------------------------------------+
| NVIDIA-SMI 580.159.03    Driver Version: 580.159.03    CUDA Version: 13.2   |
+-----------------------------------------------------------------------------+
```

**`Driver Version` 后面的数字就是你的驱动版本。** 这个例子是 580.159.03。

---

## 580 vs 595 的血泪史

| 驱动版本 | Isaac Sim 5.1.0 | 现象 |
|----------|-----------------|------|
| **580.x** | ✅ 正常 | 仿真跑起来，3D 画面正常 |
| **595.x** | ❌ 崩溃 | `Segmentation fault`，`librtx.scenedb.plugin.so` 崩溃，3D 视口黑屏 |
| 535.x | ⚠️ 没测过 | 不清楚 |

### 595 为什么会崩？

Isaac Sim 用 **Vulkan** 做 3D 渲染。Vulkan 是 NVIDIA 开发的一种底层图形 API。驱动 595.x 里 Vulkan 的某个渲染路径和 Isaac Sim 5.1.0 的 `librtx.scenedb.plugin.so` 不兼容。

这是 NVIDIA 官方已知 bug（ticket 6037337），预计在 Isaac Sim 6.0 修复。

**怎么解决？降级到 580。**

## 怎么安装/切换驱动？

```bash
# 查看可选驱动版本
ubuntu-drivers devices
# 输出会列出可用的 NVIDIA 驱动版本

# 安装 580 版本
sudo apt install nvidia-driver-580-open

# 重启（必须重启！驱动在内核里加载）
sudo reboot
```

重启后验证：

```bash
nvidia-smi | head -3
# 应该显示 Driver Version: 580.x
```

## NVIDIA Container Toolkit — 让 Docker 能访问显卡

光有驱动还不够。Docker 默认是"看不到"显卡的。**NVIDIA Container Toolkit** 就是"让 Docker 容器能借宿主机的显卡来用"。

```bash
# 安装
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey -o /tmp/nvidia-key
sudo cp /tmp/nvidia-key /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg
sudo chmod a+r /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg

curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | \
  sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | \
  sed 's/\$(ARCH)/amd64/g' | sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list

sudo apt update
sudo apt install -y nvidia-container-toolkit

# 配置 Docker 用 NVIDIA 运行时
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker
```

验证（这是最重要的验证）：

```bash
sudo docker run --rm --gpus all nvidia/cuda:12.4.1-base-ubuntu22.04 nvidia-smi
# 容器里能看到你的 GPU → ✅
```

## `nvidia-smi` 各列的含义

`nvidia-smi` 输出里表格的每一列：

```
| GPU  Name                 | Bus-Id        | Memory-Usage |
|   0  RTX 3080 Laptop GPU  | 00000000:01:00.0 |  2456MiB / 16384MiB |
```

| 列 | 含义 |
|----|------|
| GPU | GPU 编号（你有几张卡就有几行） |
| Name | 显卡型号 |
| Bus-Id | PCIe 总线地址（不用管） |
| Memory-Usage | 显存使用量 / 总量（训练时这个数字会飙升） |

## 常见问题

### `nvidia-smi` 说 "No devices were found"
→ 驱动没装或版本不对。重装 `nvidia-driver-580-open` 然后重启。

### `docker run --gpus all` 说 "could not select device driver"
→ NVIDIA Container Toolkit 没装或没配。跑 `sudo nvidia-ctk runtime configure --runtime=docker && sudo systemctl restart docker`。

### 我想同时装两个驱动版本，切换用？
→ 不行。同一时间只能有一个版本的驱动在跑。但可以用 `prime-select` 在集显和独显之间切换（笔记本常见）。
