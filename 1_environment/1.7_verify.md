# 最终验证 — 确认一切就绪

## 验证清单

在终端里按顺序跑下面每条命令，全部通过就是 ✅。

```bash
# ═══ 1. GPU 驱动 ═══
nvidia-smi
# ✅ 看到你的 GPU 型号 + "Driver Version: 580.x"

# ═══ 2. Docker GPU 直通 ═══
sudo docker run --rm --gpus all nvidia/cuda:12.4.1-base-ubuntu22.04 nvidia-smi
# ✅ 容器内能看到 GPU

# ═══ 3. Isaac Sim 镜像 ═══
sudo docker images | grep isaac-sim
# ✅ 看到 nvcr.io/nvidia/isaac-sim 5.1.0

# ═══ 4. pip 依赖 ═══
pip --version
# ✅ pip 可用

# ═══ 5. ROS 2（实机部署用，可选） ═══
source /opt/ros/lyrical/setup.bash && ros2 -h
# ✅ 看到 ROS 2 帮助信息（或跳过——如果没装）

# ═══ 6. G1 仓库 ═══
ls sim/unitree_rl_lab/scripts/rsl_rl/train.py
ls sim/unitree_ros/robots/g1_description/
ls sim/IsaacLab/source/isaaclab_rl/
# ✅ 三个仓库都在

# ═══ 7. 启动脚本 ═══
ls scripts/start.sh
# ✅ 主启动器就位
```

## 终极验证：跑一次训练

```bash
bash scripts/start.sh install   # 装训练依赖（只做一次）
bash scripts/start.sh train     # 跑训练！
```

训练启动成功后你应该看到：

```
=== G1 RL Training (headless) ===
Task: Unitree-G1-29dof-Velocity  Envs: 4  Iter: 20000

GPU | NVIDIA GeForce RTX 3080 Laptop.. | 16384 MB

                          Learning iteration 1/20000
                            Total steps: 96
                       Steps per second: 112
```

**如果看到这个输出，环境就完全就绪了！**
