# Jupyter Notebook 是什么？怎么用？

> `notebooks/` 目录里的 `.ipynb` 文件不是普通文档——是**能跑代码的文档**。

---

## 一句话：Markdown + 可逐段执行的 Python 代码

```
┌──────────────────────────────────────────┐
│ ┌—— Markdown Cell（文字解释）——————————┐  │
│ │ # 网格世界 Q-Learning                 │  │
│ │ 老鼠在 4×4 格子里找奶酪，纯 NumPy 实现。│  │
│ └──────────────────────────────────────┘  │
│ ┌—— Code Cell（可执行的 Python 代码）——┐  │
│ │ import numpy as np                     │  │
│ │ Q = np.zeros((16, 4))                  │  │
│ │ print(Q.shape)                         │  │
│ └──────────────────────────────────────┘  │
│ ◀ 代码输出: (16, 4)                       │
└──────────────────────────────────────────┘
```

每个 **Cell** 可以独立执行。改一个 Cell 不影响别的——除非你重新跑。

---

## 怎么启动

```bash
pip install jupyter
jupyter notebook
```

浏览器自动打开 `http://localhost:8888`。点 `notebooks/` → 点 `.ipynb` 文件。

---

## 3 个按键（最常用）

| 按键 | 做什么 |
|------|--------|
| `Shift + Enter` | 运行当前 Cell |
| `b` | 在下面插入新 Cell |
| `m` / `y` | 切换 Markdown / Code |

---

## 这个项目里为什么用 Notebook？

1. 边看边跑——读到概念立刻验证
2. 填空式——关键代码留 `# TODO`，自己填完按 Shift+Enter 看结果
3. 不需要 Isaac Sim——普通电脑就能学 RL
