## 核心代码在哪？

| 部分 | 文件 | 作用 |
|------|------|------|
| 启动入口 | `scripts/start.sh` | 拼 docker 命令，选 train/play/shell 模式 |
| 训练主程序 | `sim/unitree_rl_lab/scripts/rsl_rl/train.py` | 加载配置、创建环境、启动 PPO 训练 |
| 环境配置 | `sim/unitree_rl_lab/.../velocity_env_cfg.py` | 地形、奖励、观测、终止条件、物理参数 |
| 算法配置 | `sim/unitree_rl_lab/.../rsl_rl_ppo_cfg.py` | PPO 超参数、网络结构 |
| 回放程序 | `sim/unitree_rl_lab/scripts/rsl_rl/play.py` | 加载 checkpoint，导出 ONNX |
| 参数解析 | `sim/unitree_rl_lab/scripts/rsl_rl/cli_args.py` | 命令行参数 → 配置对象 |
| IsaacSim 引擎 | **Docker 镜像内**（不在 sim/ 里） | 物理仿真 + 3D 渲染 |
| PPO 算法实现 | **Docker 镜像内的 rsl-rl-lib** | 训练循环：collect → learn → repeat |

## Docker 容器里挂载了什么？

```
宿主机（你的真实电脑）                容器（Docker 里的迷你 Ubuntu）
┌─────────────────────────┐      ┌──────────────────────────────┐
│ ~/projects/g1-rl/sim/   │ ←──→ │ /sim/                         │
│   ├─ unitree_rl_lab/    │      │   ├─ unitree_rl_lab/    (RW)  │
│   ├─ unitree_ros/       │      │   ├─ unitree_ros/       (RW)  │
│   └─ IsaacLab/          │      │   └─ IsaacLab/          (RW)  │
│                         │      │                               │
│ ~/projects/g1-rl/logs/  │ ←──→ │ /isaac-sim/logs/       (RW)  │
│                         │      │                               │
│ ~/.cache/isaac-sim/     │ ←──→ │ /isaac-sim/kit/cache/  (RW)  │
│ ~/.cache/isaac-sim/     │ ←──→ │ /root/.cache/ov/       (RW)  │
│ ~/.cache/isaac-sim/     │ ←──→ │ /root/.cache/pip/      (RW)  │
│ ~/.cache/isaac-sim/     │ ←──→ │ /root/.cache/nvidia/GLCache/ │
└─────────────────────────┘      └──────────────────────────────┘
```

这些挂载意味着：
- **你改 `sim/` 的代码 → 容器里立刻生效**，不用重新构建镜像
- **训练日志写在宿主机硬盘上**，容器删了日志还在
- **Isaac Sim 的渲染缓存持久化**，下次启动不用重新编译着色器

## 谁在做物理仿真？谁在做 RL 训练？

```
┌─────────────────────────────────────┐
│ Isaac Sim（NVIDIA 物理引擎）          │
│ ├─ 模拟重力、碰撞、摩擦               │
│ ├─ 计算每个关节的受力                 │
│ └─ 渲染 3D 画面                      │
│                                     │
│  ↔ 每 0.02 秒交换一次数据             │
│                                     │
│ RSL-RL（PPO 训练循环）                │
│ ├─ 从 Isaac Sim 拿状态               │
│ ├─ 神经网络输出动作                   │
│ ├─ 把动作发给 Isaac Sim              │
│ ├─ 从 Isaac Sim 拿奖励               │
│ └─ 用 (状态, 动作, 奖励) 更新网络     │
└─────────────────────────────────────┘
```
