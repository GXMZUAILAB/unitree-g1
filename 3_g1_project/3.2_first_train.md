# 第一次训练 — G1 29-DOF 速度跟踪

> 你已经跑通环境验证了。现在来真正训练 G1 学会走路。
>
> 不需要懂 PPO 算法——跟着跑就行。跑完你就知道"训练机器人走路"是什么感觉了。

# 快速确认
nvidia-smi                    # ✅ 驱动 580.x

ls sim/unitree_rl_lab/        # ✅ 代码就位

## 完整流程

### 1️⃣ 安装依赖（只做一次）

```bash
bash scripts/start.sh install
```

这一步在 Isaac Sim 容器里安装 `gymnasium` 环境库和 `rsl-rl-lib` 训练库。装一次就够。

运行成功后看到 `Install complete.`。

### 2️⃣ 启动训练

```bash
# 最简命令（4 个并行环境，20000 轮）
bash scripts/start.sh train

# 或者自定义参数
TRAIN_NUM_ENVS=64 TRAIN_MAX_ITER=10000 bash scripts/start.sh train
```

| 环境变量 | 默认值 | 含义 |
|----------|--------|------|
| `TRAIN_TASK` | `Unitree-G1-29dof-Velocity` | 训练任务：G1 29自由度速度跟踪 |
| `TRAIN_NUM_ENVS` | `4` | 并行环境数（越大训练越快，但吃 GPU 显存） |
| `TRAIN_MAX_ITER` | `20000` | 训练轮数 |

## 看懂训练输出

每 0.8 秒左右一行输出，代表一轮训练迭代。关键指标：

| 指标 | 初期（第 1-500 轮） | 中期（500-5000 轮） | 后期（5000+ 轮） |
|------|---------------------|---------------------|-------------------|
| **Mean reward** | ~-10 到 -3（负的，正常） | 逐渐上升到 0-5 | 5-20+，稳定行走 |
| **Mean episode length** | 30-80 步（秒级） | 逐渐增长到 150+ 步 | 接近 400（走满 20 秒） |
| **bad_orientation** | 接近 1.0（每次摔倒） | 降到 0.5 以下 | 趋近 0（几乎不摔） |
| **Steps per second** | 100-120（4 envs 下） | 稳定在这个范围 | — |

> ⚠️ 初期 Mean reward 是负的**完全正常**。G1 还没学会走路，身体歪了、摔倒了都会被扣分。500 轮后开始站立，reward 开始从负转正。

### 预期训练时间

- **4 envs, 20000 iter** → ~4.5 小时
- **64 envs** → 更快，但 GPU 显存占用更大
- 16GB 显存 (RTX 3080 Ti) 可以安全跑到 64-128 envs

---

## 训练时 GPU 没动静？

正常。训练前 10-30 秒在编译着色器、初始化场景（CPU 密集）。之后 GPU 才会满载。

在另一个终端实时监控：
```bash
watch -n 1 nvidia-smi
```

## 模型保存和目录结构

模型自动保存到 `logs/rsl_rl/unitree_g1_29dof_velocity/<时间戳>/`：

```
logs/rsl_rl/unitree_g1_29dof_velocity/
└── 2026-06-24_15-30-00/
    ├── model_0.pt          # 训练配置（初始）
    ├── model_100.pt        # 第 100 轮的 checkpoint
    ├── model_200.pt
    ├── ...
    ├── model_20000.pt      # 最终模型
    ├── events.out.tfevents.*   # TensorBoard 事件文件
    ├── params/
    │   ├── env.yaml         # 环境配置快照
    │   └── agent.yaml       # 算法配置快照
    └── exported/
        ├── model.jit        # JIT 导出
        └── model.onnx       # ONNX 导出（部署到真机用）
```

## ⚠️ 首次训练可能遇到的兼容性修复

这个项目用 `rsl-rl-lib 5.0.1`，比 Unitree 官方仓库用的版本新。有 4 个兼容性补丁已经应用好。

`scripts/start.sh` 已经包含了这些修复的配置。如果你重新克隆了 `sim/` 下的仓库，需要重新应用。具体看 [3.7_常见问题](3.7_troubleshooting.md)。

## 调参建议

```bash
# 想让训练快一点（吃更多显存）
TRAIN_NUM_ENVS=128 TRAIN_MAX_ITER=10000 bash scripts/start.sh train

# 想看到 3D 画面（但会慢很多）
bash scripts/start.sh train-gui

# 训练跑了一晚上，想回看效果
bash scripts/start.sh play 2026-06-24_15-30-00 model_5000.pt
```

如果训练中途想停，直接 `Ctrl+C` 就行。checkpoint 已经保存到磁盘了。
