# 5.2 连接到机器人

> 在你把 AI 模型塞进机器人之前，先得能和它"说话"。
>
> 这章教你：怎么从你的电脑连上 G1 机器人的电脑。

---

## 类比：远程桌面，但是打字的

你用 Windows 的时候，如果想控制别人的电脑，可以用 QQ 远程协助——看到对方的桌面，用鼠标操作。

Linux 没有"桌面远程"的习惯。Linux 用 **SSH**——它让你在自己的终端里打字，但执行的命令是在**机器人的电脑**上跑的。

```
你的电脑                              机器人的电脑
┌─────────────────┐                   ┌─────────────────┐
│ 你打字：          │                   │                  │
│ $ ssh unitree@   │  ──── 网络 ────▶  │ 收到命令，执行    │
│   192.168.1.100  │                   │ 把结果发回来      │
│                  │  ◀─── 网络 ────   │                  │
│ 看到结果          │                   │                  │
└─────────────────┘                   └─────────────────┘
```

---

## 前提：你得和机器人在同一个网络里

G1 机器人内部是 `192.168.123.x` 网段。两种连接方式：

**方式 1：Wi-Fi**（机器人开热点或连实验室 Wi-Fi）
- 你的电脑连上同一个 Wi-Fi

**方式 2：网线直连**（推荐，更稳定）
- 网线一端插你电脑的**物理网口**（不要用 USB 转接），另一端插 G1 机箱网口
- 你的电脑需要配静态 IP（下面会教）

**G1 内部 IP 分配：**

| IP | 设备 | 用途 |
|----|------|------|
| `192.168.123.161` | 主控 MCU | 电机通信、传感器数据 |
| `192.168.123.164` | 开发板 | **SSH 登录**（用户名 `unitree`，密码 `123`） |
| `192.168.123.120` | 激光雷达 | 不用管 |

> 推送代码（deploy.sh push）的目标是 `.164` 开发板，不是 `.161` 主控。

### 网线直连：给你的电脑配静态 IP

**Ubuntu 图形界面（推荐）：**

1. 打开 **Settings → Network**
2. 找到有线连接（Wired），点 ⚙ 齿轮
3. **IPv4** 标签页 → 选 **Manual**
4. 填写：

   ```
   Address:  192.168.123.99
   Netmask:  255.255.255.0
   Gateway:  （留空）
   ```

5. 点 **Apply**

**命令行临时设置（重启失效）：**

```bash
# 先看有线网卡叫什么是（enp××× / enx×× / eth×）
ip link show | grep -E "en|eth"

# 设静态 IP
sudo ip addr add 192.168.123.99/24 dev <你的网卡名>
```

> ⚠️ 你的 IP 不能和机器人的冲突。`.161` `.164` `.120` 已被占用，选别的。

**验证连通性：**

```bash
ping 192.168.123.164    # 开发板（SSH 目标）
ping 192.168.123.161    # 主控
```

## 第一步：搞清楚机器人的 IP 地址

### 如果你能登录机器人的电脑

走到机器人旁边，它胸前/背后有一块屏幕（或者外接的显示器）。在机器人自己的电脑上打开终端，输入：

```bash
ifconfig
```

你会看到一堆输出。找到类似这样的那一块：

```
wlan0: flags=4163<UP,BROADCAST,RUNNING,MULTICAST>  mtu 1500
        inet 192.168.1.100  netmask 255.255.255.0  ...
```

`inet` 后面的 `192.168.1.100` 就是机器人的 IP。记下来。

> 怎么看 `ifconfig` 输出？找 `inet` 开头的那一行。忽略 `127.0.0.1`——那是机器人自己跟自己说话用的，不是网络 IP。

### 如果你联系不到机器人的电脑

问你的师兄/管理员。G1 的默认 IP 通常是：
- Wi-Fi 热点模式：`192.168.123.164`（开发板）
- 有线网口连接 PC：PC 设 `192.168.123.99`，SSH 到 `.164`

---

## 第二步：从你的电脑连过去

你的电脑是 Ubuntu 的话，打开终端（`Ctrl+Alt+T`）。

```bash
ssh 用户名@机器人IP
```

### 用户名是什么？

G1 机器人上的默认用户名是 `unitree`。如果你不知道：
- 问给你机器人的人
- 常见默认值：`unitree`、`nvidia`、`ubuntu`
- G1 开发板默认密码：`123`

### 实际例子

```bash
ssh unitree@192.168.1.100
```

第一次连的时候，终端会问：

```
The authenticity of host '192.168.1.100 (...)' can't be established.
...
Are you sure you want to continue connecting (yes/no/[fingerprint])?
```

**输入 `yes`，然后回车。** 这个提示只会在第一次出现，意思是"这个机器你以前没连过，确认要连吗？"

然后输入密码。输入时屏幕上**不会显示任何东西**（不会出现 `***`），这是正常的。打完直接回车。

如果密码正确，你会看到：

```
Welcome to Ubuntu 22.04.x LTS
...
unitree@g1-robot:~$
```

`unitree@g1-robot:~$` 出现的时候，**你已经连上了**！现在你打的每一条命令，都是在机器人上运行的。

---

## 断开连接

在 SSH 终端里输入：

```bash
exit
```

或者按 `Ctrl+D`。

你就回到了自己的电脑。

---

## 常见问题

### "ssh: command not found"

你的电脑没装 SSH 客户端。装一下：

```bash
sudo apt install openssh-client
```

### "Connection refused"

机器人可能没开 SSH 服务。走到机器人旁边，在它的终端里：

```bash
sudo systemctl enable ssh
sudo systemctl start ssh
```

### "Connection timed out"

- 你的电脑和机器人不在同一个网络里
- 或者 IP 写错了
- 试试用网线直连机器人（如果它有一个网口的话）

### "Permission denied, please try again"

密码不对。G1 默认密码通常是 `123`。

### 忘了机器人 IP，也连不上屏幕

如果机器人开了热点但你不确定 IP，可以试试：

```bash
# 在你的电脑上，连上机器人热点后：
ip route | grep default
# 看默认网关的 IP，机器人的 IP 通常就是这个网段的最后一截

# 或者用 nmap 扫：
nmap -sn 192.168.123.0/24
# 会列出这个网段里所有在线的设备
```

---

## 总结

你现在需要记住的东西：

- **SSH** = 在你自己电脑上打字，代码在机器人上跑
- **连接命令** = `ssh unitree@<机器人IP>`
- **断开** = `exit` 或 `Ctrl+D`
