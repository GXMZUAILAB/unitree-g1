# 硬件实测

> RTX 3080 Laptop GPU (16GB VRAM) + AMD Ryzen 7 6800HS (8C/16T) + 14GB RAM 的实际表现。

---

## 配置概要

| 组件 | 型号 | 关键参数 |
|------|------|---------|
| GPU | NVIDIA RTX 3080 Laptop | 16GB VRAM, TDP 150W, PCIe 3.0 ×8 |
| CPU | AMD Ryzen 7 6800HS | 8 核 16 线程, 4.7GHz boost |
| RAM | DDR5 | 14 GB |
| 存储 | NVMe SSD | 300 GB (~238 GB 空闲) |
| 散热 | 笔记本内置 | GPU throttle 阈值 93°C |

---

## envs 数量对 GPU 利用率的影响

测试条件：G1 29-DOF Velocity Tracking, decimation=4, dt=0.005

| envs | GPU 利用率 | 显存 | 功耗 | 系统内存 | 温度 |
|------|:---------:|:----:|:----:|:--------:|:----:|
| 4 | 50% | 3.4G (21%) | 51W (34%) | — | 72°C |
| 4096 | 77% | 6.7G (42%) | 98W (65%) | — | 85°C |
| 8192 | 81% | 9.6G (60%) | 103W (69%) | 12.6/14G (87%) | 84°C |

### 关键发现

1. **4 envs 喂不饱 GPU**：batch size 太小，GPU 大量时间在 idle 等待 CPU PhysX 仿真
2. **4096 是甜点**：GPU 77%，显存 6.7G，系统内存安全
3. **8192 收益递减**：GPU 利用率只提了 4%，但系统内存推到 87% + swap
4. **瓶颈在 CPU 物理仿真**：GPU 利用率无法到 99% 的原因是 PhysX 仿真跟不上

## PPO 训练周期

```
每个 iteration (2.64s @ 4096 envs):
┌──────────────────────────────────────┐
│ 1. 数据采集 (2.31s = 87%)              │
│    PhysX 仿真 4096 robots × 24 steps   │
│    GPU 在此阶段 idle ← 这是瓶颈        │
│                                        │
│ 2. 策略更新 (0.33s = 13%)              │
│    PPO gradient steps on 98304 trans   │
│    GPU 在此阶段满载                     │
└──────────────────────────────────────┘
```

这是 on-policy RL 的天然特征，不必纠结 99% GPU。

---

## 推荐配置

| 硬件 | 推荐 envs | 备注 |
|------|:--------:|------|
| 16G VRAM + 14G RAM（当前） | 4096 | 不要超过 8192 |
| 16G VRAM + 32G RAM | 8192 | 加内存后可翻倍 |
| 24G VRAM + 32G RAM | 16384 | 接近原始配置文件默认值 |

---

## 功耗与温度

- 长期训练（12h+）：GPU 稳定在 84-85°C，功耗 100-103W
- GPU throttle 阈值 93°C，还有 ~8°C 余量
- 建议：确保笔记本底部通风，长期跑考虑加散热底座
