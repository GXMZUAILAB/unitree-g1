# Unitree G1 舞蹈机器人开发指南 (Main Development Guide)

这份指南为学生和研究人员提供了从零开始开发 Unitree G1 强化学习舞蹈项目的详细步骤。

## 1. 前置条件

- **操作系统**：Ubuntu 20.04 / 22.04
- **显卡**：安装驱动的 NVIDIA 显卡（推荐支持 CUDA 12.1）
- **工具链**：
    - Conda (Python 3.8)
    - Isaac Gym Preview 4
    - ROS2 Humble
    - Unitree SDK2
- **数据集**：AMASS / LAFAN1 (BVH 格式)

---

## 2. 核心技术任务分解

### 任务 01：环境与工具链搭建

**目标**：搭建统一开发环境并验证核心工具可用性。

1.  **Conda 环境**：创建并激活 Conda 环境（Isaac Gym 要求 Python 3.8），安装支持 CUDA 12.1 的 PyTorch。
2.  **Isaac Gym**：手动安装 Isaac Gym Preview 4（需从 NVIDIA 开发者网站下载），并通过 `joint_monkey.py` 示例验证安装有效性。
3.  **RSL_RL**：克隆并安装 `rsl_rl`（切换至 `v1.0.2` 稳定版本），用于优化后的 PPO 算法实现。
4.  **SDK 与 ROS2**：安装宇树 SDK2 与 ROS2 Humble，通过 SDK 示例验证与 G1 机器人的通信功能。

### 任务 02：运动数据准备与处理

**目标**：制备标准化 BVH 数据，用于 G1 机器人动作重定向。

1.  **数据筛选**：从 AMASS/LAFAN1 数据集提取 BVH 片段，过滤掉超出 G1 关节活动范围的动作。
2.  **动作重定向 (Retargeting)**：使用 GMR 或类似工具完成人体动作到 G1 机器人的重定向，优化轨迹平滑度及重心稳定性。
3.  **数据清洗**：清洗异常帧（关节超限、姿态突变帧），并转换为 HDF5 格式（适配 Isaac Gym/RSL_RL）。
4.  **验证**：在 Isaac Gym 中播放处理后的数据，验证无姿态畸变问题。

### 任务 03：Isaac Gym 仿真环境配置

**目标**：搭建并校准 G1 机器人仿真环境，用于强化学习训练。

1.  **模型导入**：将官方 G1 URDF 模型导入 Isaac Gym，加载默认动力学参数（阻尼、摩擦、质量分布），**禁止擅自修改**。
2.  **物理引擎**：启用高精度 PhysX 物理引擎，同步仿真频率与 G1 原生控制频率。
3.  **空间定义**：配置强化学习训练所需的状态/动作空间（关节角度、速度、重心、关节力矩），适配 RSL_RL 接口。
4.  **环境校准**：校准环境以避免模型穿模，确保动作播放与处理后的数据一致。

### 任务 04：强化学习模型 (BC+PPO) 基础训练

**目标**：基于 RSL_RL 实现 BC（行为克隆）预训练与 PPO 初始训练。

1.  **奖励函数**：定义奖励函数，优先考虑轨迹匹配度与姿态稳定性，增设关节超限、摔倒惩罚项。
2.  **BC 预训练**：使用 HDF5 数据集执行 BC 预训练，加速模型收敛并初始化基础舞蹈姿态。
3.  **PPO 训练**：以预训练 BC 模型为初始值启动 PPO 训练，通过 RSL_RL 配置文件调整学习率与批次大小。
4.  **复现验证**：确保模型可在仿真环境中完整复现舞蹈动作，无训练中途失效问题。

### 任务 05：强化学习模型迭代与仿真验证

**目标**：优化模型性能并验证其在仿真环境中的鲁棒性。

1.  **超参调优**：基于 TensorBoard 日志调优模型超参数，解决动作卡顿、姿态失衡、力矩异常等问题。
2.  **鲁棒性验证**：在轻微扰动环境中（地面摩擦系数/负载小幅变化）验证模型，确保鲁棒性。
3.  **版本管理**：对优化后的模型进行版本管理，记录训练配置与验证结果，便于追溯。
4.  **稳定性确认**：连续 3 轮仿真运行无失效，满足基础动作复现要求。

### 任务 06：实物机器人指令适配

**目标**：搭建仿真输出与 G1 机器人可执行指令的通信桥梁。

1.  **Sim2Real 转换**：开发转换脚本，将 Isaac Gym 关节轨迹映射为宇树 SDK2 兼容的控制指令，同步控制频率。
2.  **通信测试**：建立与 G1 的 ROS2 通信链路，验证指令延迟与状态反馈精度（无丢包）。
3.  **单动作测试**：在实物 G1 上测试核心单动作（挥手、踏步、转身），验证指令解析及关节动作合规性。
4.  **一致性排查**：排查通信/指令错误，确保仿真与实物动作执行一致性。

### 任务 07：实物机器人测试与域差距校准

**目标**：完成实物机器人部署及动作优化。

1.  **分阶段测试**：单动作 → 动作片段 → 完整舞蹈，初始降低动作幅度以规避硬件风险。
2.  **动力学校准**：校准动力学补偿参数，缩小仿真到实物的域差距 (Sim-to-Real Gap)，使实物动作流畅度与仿真一致。
3.  **长期稳定性**：G1 连续 5 次完整执行舞蹈动作无硬件故障。
4.  **部署报告**：记录测试结果、参数调整及问题解决方案，形成完整部署报告。
