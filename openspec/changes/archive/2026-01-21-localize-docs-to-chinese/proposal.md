# Change: Localize Documentation to Chinese

## Why
To make the documentation more accessible to Chinese-speaking developers while maintaining precise technical terminology by keeping key English terms.

## What Changes
- Set Chinese as the primary language for all `.md` files in the repository.
- **RESTRICTION**: Technical terms (e.g., Isaac Sim, Reinforcement Learning, PPO, Hydra) SHALL stay in English.
- Update `openspec/project.md` to reflect this new documentation convention.

## Impact
- Affected specs: documentation-standards
- Affected code: All markdown documentation files.
