## ADDED Requirements
### Requirement: Primary Language is Chinese
All documentation SHALL use Chinese as the primary language to ensure accessibility for the target development team.

#### Scenario: Translating new docs
- **WHEN** a new documentation file is created
- **THEN** its primary content is written in Chinese.

### Requirement: Preservation of English Technical Terms
Technical terms, library names, and system components SHALL remain in English to maintain terminology precision and avoid ambiguity.

#### Scenario: Using technical terms
- **WHEN** referring to "Reinforcement Learning" or "Isaac Lab"
- **THEN** these exact English terms are used within the Chinese text.
